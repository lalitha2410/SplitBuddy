# 💸 SplitBuddy

SplitBuddy is a clean and modern web application that helps groups, friends, and roommates split expenses fairly with transparent settlements.  
Built with a highly interactive UI, WebGL visuals, smooth motion, and smart expense logic.

---

## 🚀 Features

- ➕ Create Groups
- 🧍 Add Group Members
- 🧾 Add Expenses (description, payer, split-members, amount)
- ⚖️ Automatic balance calculations
- 🔁 Smart settlement calculation (who pays who and how much)
- 💾 LocalStorage persistence
- 📱 Fully responsive UI (mobile → desktop)
- 🎨 Tailwind styling + glassmorphism
- 🎥 Motion animations (Framer Motion)
- 🌐 WebGL background powered by React Fiber + Drei
- ⚛️ Zustand for clean global state management

---

## 🧰 Tech Stack

| Layer | Stack |
|---|---|
| UI | React + Vite |
| Styling | Tailwind CSS |
| Animations | Framer Motion |
| 3D/WebGL | Three.js + @react-three/fiber + Drei |
| State | Zustand |
| Routing | React Router |
| Persistence | LocalStorage |
| Deployment | Vercel (recommended) |
